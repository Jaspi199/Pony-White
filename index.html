Square Online Deployment Guide

1

Select a Page and Copy Embed Code

Click the "Copy Embed" button on any of the page cards above. The system automatically copies the pre-compiled, fully-inlined single-line HTML string directly to your clipboard.

2

Paste into Square Online Custom HTML

Open your Square Online website builder dashboard. Drag a "Custom Embed Code" or "HTML Section" block onto your desired page. Click in the code configuration input, and paste (⌘V or Ctrl+V) the single line of code.

3

How Image Asset Hosting Works

During compilation, local image URLs are automatically mapped to reference the public jsDelivr CDN (https://cdn.jsdelivr.net/gh/Jaspi199/Pony-White@main/assets/...). Once you push your local repository changes to your GitHub branch, all images will instantly load perfectly on the live Square site!
